# Roadmap e critérios de aceite

## MVP-001 — protótipo local
- [x] Interface HTML/CSS/JS responsiva
- [x] API Node.js sem dependências externas
- [x] Narrativa simulada determinística
- [x] Prévia e impressão em PDF pelo navegador
- [x] Testes unitários e workflow CI
- [ ] Validar execução do workflow e inspeção visual
- [ ] Persistência e edição de projetos
- [ ] PDF gerado no servidor

## MVP-002 — IA real (não implementado)
- Adaptadores de LLM e geração de imagens com mocks nos testes
- Fila de tarefas, retries e limites de custo
- Revisão de segurança e adequação etária
- Consistência visual de personagens

## MVP-003 — comercial (não implementado)
- Contas, pagamentos, biblioteca privada, exclusão de dados
- Avaliação jurídica LGPD e controles de privacidade
- Monitoramento, segurança e implantação

Não usar dados pessoais reais de crianças no protótipo. Sem deploy automático, chaves ou serviços pagos.
