# e-books

Plataforma independente para criação de livros infantis personalizados.

## Estado

MVP em desenvolvimento. Não utilizar dados reais de crianças nesta fase.

## Diretrizes

- HTML, CSS e JavaScript no frontend.
- Node.js no backend.
- Geração simulada local antes de integrar provedores pagos de IA.
- Privacidade e revisão humana antes da publicação.
